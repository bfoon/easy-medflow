Ask for an ambulance

POST /requests/ as JSON{% if needs_key %} with the header X-App-Key{% else %}. This server has no app key set (development){% endif %}:

{{ sample }}

The answer has a token and a tracking_url. Poll /requests/<token>/ every 10 seconds for the ambulance position and ETA. The request reaches the service desk as “waiting for call-back”, so keep the phone line free.

Get the complaint list and its questions from /meta/ so the app always asks what the service desk asks.

Crew app sign-in

Pair from the crew screen (QR code), or POST /auth/token/ with username, password, device_name. Send the token as Authorization: Bearer ems_….

While driving, POST /crew/position/ every 5–10 seconds. The first fix above 10 km/h marks the ambulance “on the way”; each fix updates the ETA the caller and the hospital see.

Errors

Always JSON: {"ok": false, "error": "…"}. 401 bad key or token, 403 not allowed, 404 unknown, 409 not possible in the current state (e.g. cancelling after the crew arrived), 429 too many requests.
